# readmelens.github.io

The landing page for **[ReadmeLens](https://github.com/SolankiYogesh/ReadmeLens)**,
a free, open-source Markdown viewer for macOS.

Served at <https://readmelens.github.io/>.

The app itself — source, issues and releases — lives in the
[main repository](https://github.com/SolankiYogesh/ReadmeLens).

## Editing

`index.html` is a single self-contained page: styles inline, no build step, no
dependencies. Edit it and push; GitHub Pages redeploys within a minute.

Images are copied from the app repository's `docs/` folder. The social card is
generated by `Tools/GenerateSocialCard.swift` over there rather than being an
opaque bitmap.
